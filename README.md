One prompt in, one game out: an AI agent takes the prompt "Build a tiny browser game: a neon snake that speeds up every time it eats, with a score counter and game-over screen", writes the whole game as a single HTML file, plays it on camera, and posts the video on X — prompt, coding, gameplay and the make.fun referral end card in one 50-second clip. This repository hands in that post's address: `main.ts` copies `POST.json` to the output directory, and the house reads the post's views and interactions from X itself.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
